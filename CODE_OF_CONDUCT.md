# Code of Conduct

This project follows a simple standard: be respectful, constructive, and focused on the work.

## Expected Behavior

- Use welcoming and inclusive language.
- Accept constructive feedback.
- Keep technical disagreement specific and professional.
- Avoid sharing private information or credentials.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Publishing private information without permission.
- Posting real API keys, access tokens, or other secrets.

## Enforcement

Maintainers may remove comments, close issues, or block participants who violate this code of conduct. Reports can be made privately to the project maintainers.
